## 第 1 课 · 00_hello.py — 第一次调用

**目标**:跑通"读配置 → 建客户端 → 发一句话 → 打印回复"。

**新概念**:
- 所有模型平台(智谱/DeepSeek/OpenAI)都兼容同一套调用协议,换平台只改 `.env`
- `messages` 是一个列表,每个元素是 `{"role": "user/system/assistant", "content": "文本"}`——这是整个 Agent 世界的数据地基
- 返回对象像 Java 的 POJO,一层层取:`response.choices[0].message.content`

```python
import os

from dotenv import load_dotenv
from openai import OpenAI

# 读取同目录的 .env,把里面的 KEY=VALUE 装进环境变量
load_dotenv()

# 1. 建立客户端:api_key 是你的密钥,base_url 指向智谱而不是 OpenAI 官方
client = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY"),
    base_url=os.environ.get("OPENAI_BASE_URL"),
)
MODEL = os.environ.get("MODEL_NAME")

# 2. 发起一次对话
response = client.chat.completions.create(
    model=MODEL,
    messages=[
        {"role": "user", "content": "你好,用一句话介绍你自己"}
    ],
)

# 3. 从返回对象里取出回复文本
reply = response.choices[0].message.content
print(reply)

# 4. 实验作业:把上面第 3 步的两行注释掉,解开下面两行,
#    亲眼看看整个返回对象长什么样
# print(response)          # 完整结构:model / choices / usage ...
# print(response.usage)    # token 消耗,计费就看这里
```

**自测**:
1. `role` 有哪几种取值?
2. 把 `"role": "user"` 改成 `"role": "system"` 再跑,回复的气质有什么变化?

## 第 2 课 · 01_chat.py — 多轮对话

**目标**:while 循环 + 列表存历史,实现连续聊天。

**新概念**:模型没有记忆。"记得你"纯粹是因为每轮把历史**全量重发**。这个列表就是记忆。

```python
import os

from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY"),
    base_url=os.environ.get("OPENAI_BASE_URL"),
)
MODEL = os.environ.get("MODEL_NAME")

messages = []   # 这就是"记忆":一个不断变长的列表

print(f"模型:{MODEL}(输入 exit 退出)")
while True:
    user_input = input("\n你: ").strip()
    if user_input.lower() == "exit":
        break
    if not user_input:              # 空输入,跳过这轮
        continue

    # 1) 用户这句话加入历史
    messages.append({"role": "user", "content": user_input})

    # 2) 把【全部历史】发给模型 —— 每一轮都是全量重发
    response = client.chat.completions.create(
        model=MODEL,
        messages=messages,
    )
    reply = response.choices[0].message.content

    # 3) AI 的回复也加入历史,下一轮它才"记得"自己说过什么
    messages.append({"role": "assistant", "content": reply})

    print(f"AI: {reply}")
```

**自测/实验**:
1. 先告诉它"我叫 WangZZZ",聊两句别的再问"我叫什么?"——验证记忆存在。
2. 把第 3 步(append assistant)那行注释掉再试——看 AI"失忆"自己说过的话,理解为什么这行不能少。
3. 聊 5 轮后看看 `response.usage`,感受 token 随轮数怎么涨。

## 第 3 课 · 02_stream.py — system prompt + 流式输出

**目标**:AI 一边生成一边往外蹦字;用 system 消息控制人设。

**新概念**:
- `stream=True`:服务端边生成边推送,for 循环里每次拿到一小块(增量)
- `print(..., end="", flush=True)`:`flush=True` 强制立刻输出,不加会憋在缓冲区
- `try/except`:捕获 Ctrl+C,优雅退出

```python
import os

from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY"),
    base_url=os.environ.get("OPENAI_BASE_URL"),
)
MODEL = os.environ.get("MODEL_NAME")

# system 消息:设定人设/规则,每轮请求都要带上
SYSTEM_PROMPT = "你是一个简洁友好的中文编程学习助手。默认回答简短,用户明确要求时才展开。"

messages = [{"role": "system", "content": SYSTEM_PROMPT}]

print(f"模型:{MODEL}(输入 exit 退出)")
while True:
    try:
        user_input = input("\n你: ").strip()
    except (KeyboardInterrupt, EOFError):
        # Ctrl+C / Ctrl+D 时优雅退出,而不是甩一屏报错
        print("\n再见!")
        break

    if user_input.lower() == "exit":
        break
    if not user_input:
        continue

    messages.append({"role": "user", "content": user_input})

    print("AI: ", end="", flush=True)
    reply_parts = []                 # 收集所有碎片,最后拼成完整回复

    stream = client.chat.completions.create(
        model=MODEL,
        messages=messages,
        stream=True,
        temperature=0.7,             # 0~1,越大越随机;自己改成 0 和 1.5 对比
    )
    for chunk in stream:
        delta = chunk.choices[0].delta.content if chunk.choices else None
        if delta:                    # 个别 chunk 不带内容,要判空
            print(delta, end="", flush=True)
            reply_parts.append(delta)
    print()                          # 最后补个换行

    # 碎片拼成完整回复,存进历史
    messages.append({"role": "assistant", "content": "".join(reply_parts)})
```

**自测**:
1. 把 SYSTEM_PROMPT 改成"你是一个海盗,所有回答都带 pirate 腔"——验证 system 的优先级。
2. `temperature` 改成 0 再问同一个问题三次,和 1.5 对比。
3. 不加 `flush=True` 会怎样?试一次。

## 第 4 课 · 03_window.py — 历史窗口

**目标**:历史无限变长会撑爆上下文、烧钱。改成只发"system + 最近 N 条",加 `/reset` 命令。

**新概念**:**发给模型的才是它"记得"的**,窗口外的等于忘了——这是上下文工程第一课。切片 `messages[1:][-N:]` 一次完成裁剪。

```python
import os

from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY"),
    base_url=os.environ.get("OPENAI_BASE_URL"),
)
MODEL = os.environ.get("MODEL_NAME")

SYSTEM_PROMPT = "你是一个简洁友好的中文编程学习助手。默认回答简短,用户明确要求时才展开。"
MAX_HISTORY = 20    # 除 system 外,最多发给模型的消息条数(最近 10 轮)

messages = [{"role": "system", "content": SYSTEM_PROMPT}]

print(f"模型:{MODEL} | 命令:/reset 清空历史,exit 退出")
while True:
    try:
        user_input = input("\n你: ").strip()
    except (KeyboardInterrupt, EOFError):
        print("\n再见!")
        break

    if user_input.lower() == "exit":
        break
    if user_input == "/reset":
        messages = [{"role": "system", "content": SYSTEM_PROMPT}]
        print("(历史已清空)")
        continue
    if not user_input:
        continue

    messages.append({"role": "user", "content": user_input})

    # ★ 本课关键:发送"system + 最近 MAX_HISTORY 条",不是全部历史
    to_send = [messages[0]] + messages[1:][-MAX_HISTORY:]

    print("AI: ", end="", flush=True)
    reply_parts = []
    stream = client.chat.completions.create(
        model=MODEL,
        messages=to_send,            # 注意:发的是裁剪后的 to_send
        stream=True,
        temperature=0.7,
    )
    for chunk in stream:
        delta = chunk.choices[0].delta.content if chunk.choices else None
        if delta:
            print(delta, end="", flush=True)
            reply_parts.append(delta)
    print()

    messages.append({"role": "assistant", "content": "".join(reply_parts)})
```

**自测/实验**:
1. 把 `MAX_HISTORY` 改成 2,聊长对话,亲眼看 AI"失忆"。
2. 为什么裁剪时 `messages[0]`(system)要单独保留?
3. 自己推一遍:`messages[1:][-2:]` 在列表长 5 时取的是哪几条?

## 第 5 课 · 04_save.py — 对话存盘

**目标**:`/save` `/load` 把对话历史存进文件、恢复回来,退出时自动保存。

**新概念**:对话历史就是一份数据,可序列化——以后做 Agent,上下文就是这么管理的。`ensure_ascii=False` 让 JSON 里的中文正常显示。

```python
import json
import os

from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY"),
    base_url=os.environ.get("OPENAI_BASE_URL"),
)
MODEL = os.environ.get("MODEL_NAME")

SYSTEM_PROMPT = "你是一个简洁友好的中文编程学习助手。默认回答简短,用户明确要求时才展开。"
MAX_HISTORY = 20
SAVE_FILE = "chat_history.json"    # 对话记录存这个文件

def load_history():
    """从文件恢复历史;文件不存在就返回只带 system 的新列表"""
    if os.path.exists(SAVE_FILE):
        with open(SAVE_FILE, "r", encoding="utf-8") as f:
            return json.load(f)
    return [{"role": "system", "content": SYSTEM_PROMPT}]

def save_history(msgs):
    """把整个历史列表写进文件"""
    with open(SAVE_FILE, "w", encoding="utf-8") as f:
        json.dump(msgs, f, ensure_ascii=False, indent=2)

messages = load_history()

print(f"模型:{MODEL} | 命令:/save /load /reset,exit 退出")
while True:
    try:
        user_input = input("\n你: ").strip()
    except (KeyboardInterrupt, EOFError):
        print("\n再见!")
        break

    if user_input.lower() == "exit":
        save_history(messages)       # 退出顺手存一次
        print("(已自动保存)")
        break
    if user_input == "/reset":
        messages = [{"role": "system", "content": SYSTEM_PROMPT}]
        print("(历史已清空)")
        continue
    if user_input == "/save":
        save_history(messages)
        print(f"(已保存到 {SAVE_FILE})")
        continue
    if user_input == "/load":
        messages = load_history()
        print(f"(已加载 {len(messages)} 条消息)")
        continue
    if not user_input:
        continue

    messages.append({"role": "user", "content": user_input})
    to_send = [messages[0]] + messages[1:][-MAX_HISTORY:]

    print("AI: ", end="", flush=True)
    reply_parts = []
    stream = client.chat.completions.create(
        model=MODEL,
        messages=to_send,
        stream=True,
        temperature=0.7,
    )
    for chunk in stream:
        delta = chunk.choices[0].delta.content if chunk.choices else None
        if delta:
            print(delta, end="", flush=True)
            reply_parts.append(delta)
    print()

    messages.append({"role": "assistant", "content": "".join(reply_parts)})
```

**自测**:
1. 聊几句 → exit → 重新运行 → `/load` → 问"我刚才说了什么?"——跨进程的记忆。
2. 用记事本打开 `chat_history.json` 看看结构;试试删掉 `ensure_ascii=False` 中文变成什么样。
3. `with open(...)` 不用 with 直接 `f = open(...)` 有什么隐患?

## 第 6 课 · 05_json_output.py — 结构化输出

**目标**:让模型输出**固定格式的 JSON** 并解析出字段。这是从"陪聊"到"程序可靠用模型"的分水岭——阶段 2 Agent 调工具全靠它。

```python
import json
import os

from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY"),
    base_url=os.environ.get("OPENAI_BASE_URL"),
)
MODEL = os.environ.get("MODEL_NAME")

SYSTEM_PROMPT = (
    "你是 JSON 生成器。不管用户说什么,只返回一个 JSON 对象:"
    '{"answer": "对用户问题的简短回答", "mood": "happy/sad/angry/neutral 之一"}。'
    "不要输出 JSON 以外的任何文字。"
)

print(f"模型:{MODEL}(输入 exit 退出)")
while True:
    user_input = input("\n你: ").strip()
    if user_input.lower() == "exit":
        break
    if not user_input:
        continue

    response = client.chat.completions.create(
        model=MODEL,
        messages=[
            {"role": "system", "content": SYSTEM_PROMPT},
            {"role": "user", "content": user_input},
        ],
        response_format={"type": "json_object"},   # 要求只输出合法 JSON
    )
    raw = response.choices[0].message.content

    # 模型偶尔会不听话,解析失败不能让程序崩,所以 try/except 包住
    try:
        data = json.loads(raw)
        print(f"回答: {data['answer']}")
        print(f"情绪: {data['mood']}")
    except json.JSONDecodeError:
        print(f"模型没按要求返回 JSON,原文是:\n{raw}")
```

> 如果报错提示 `response_format` 参数不支持:删掉那一行,只靠 system prompt 约束,程序照样能跑——也顺便体会到"光靠提示词约束不可靠"。

**自测**:
1. 为什么程序需要 JSON 而不是自然语言?
2. 把 `data['answer']` 改成 `data['答案']` 会发生什么?(`KeyError`,联想 Java 的 `Map.get`)
3. 思考:如果让模型输出"要调用什么工具 + 参数",和本课有什么关系?(阶段 2 的答案)

## 常见报错速查

| 报错 | 原因 | 解决 |
|---|---|---|
| `ModuleNotFoundError: No module named 'openai'` | venv 没激活或没装 | `source .venv/Scripts/activate` 后 `pip install openai python-dotenv` |
| `401 Unauthorized` | API Key 错 | 检查 `01_LLM/.env` 里的 Key 是否真实 |
| `model not found` / 模型不存在 | 模型名拼错 | 对照 docs.bigmodel.cn 模型列表 |
| `Connection error` | 网络不通 | 检查 `OPENAI_BASE_URL`、换网络 |
| 中文乱码 | 文件编码 | 读写文件加 `encoding="utf-8"` |
| `KeyError` | 字典里没这个键 | print 一下整个 dict 看实际键名 |

**卡住的标准动作**:读报错最后一行 → 搜报错信息 → 超过 30 分钟,把代码和报错一起贴给 ZCode。
