## 第 0 课 · 概念 + 环境（先读后敲，30 分钟）

### 核心问题

**生产化 Agent 和 demo 的区别在哪？**

Demo：能跑就行，报错了人工重启，输出格式不对就手动解析。  
生产：稳定性 > 功能性，要求自动重试、结构化输出、可观测、可评测、可扩展。

   https://www.anthropic.com/research/building-effective-agents

   https://python.useinstructor.com/  
   重点：Retry logic、Validation with Pydantic

3. **mem0 文档**：Memory for AI Agents

|------|-----------|----------|----------------|

### 技术选型原则（企业视角）

1. **结构化输出**：Instructor（Pydantic 集成好）> 裸 JSON mode（要自己写重试）
2. **记忆**：mem0（专门做记忆）> 自己写向量检索（轮子太重）
3. **向量库**：
   - 学习 / 小项目：chromadb（轻量）
   - 生产 / 大数据：Milvus（分布式）、Pinecone（托管但收费）
4. **可观测**：LangSmith（官方但收费）、Langfuse（开源可自部署）
5. **Agent 框架**：
   - 快速原型：OpenAI Swarm（轻量，100 行代码）
   - 复杂工作流：LangGraph（你阶段 6 没学，但企业用得多）
   - 手写：阶段 1-6 教会你的，适合定制需求

### 阶段 7 vs 前面阶段的关系

## 第 1 课 · Instructor 结构化输出（60 分钟）

### 目标

用 Instructor 强制模型返回符合 Pydantic Schema 的 JSON，失败自动重试（最多 3 次），彻底解决"模型返回格式不对"的问题。

### 核心概念

**Instructor = Pydantic + OpenAI SDK + 自动重试逻辑**

```python
# 阶段 4 的做法（手动重试）
response = client.chat.completions.create(
    model=MODEL,
    messages=[...],
    response_format={"type": "json_object"}
)
try:
    result = UserInfo.model_validate_json(response.choices[0].message.content)
except ValidationError:
    # 手动重试...

# Instructor 的做法（自动重试）
import instructor
client = instructor.from_openai(OpenAI(...))

result = client.chat.completions.create(
    model=MODEL,
    response_model=UserInfo,  # Pydantic model
    messages=[...],
    max_retries=3
)
# result 保证是 UserInfo 实例，格式错误已自动重试
```

### 完整代码：`01_instructor.py`

```python
# -*- coding: utf-8 -*-
"""
Instructor 结构化输出示例
对比：阶段 4 手写 Pydantic 校验 vs Instructor 自动重试
"""
import os
from dotenv import load_dotenv
from openai import OpenAI
import instructor
from pydantic import BaseModel, Field, ValidationError
from typing import List

load_dotenv()

# ---- 配置 ----
client_raw = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY"),
    base_url=os.environ.get("OPENAI_BASE_URL")
)
client_instructor = instructor.from_openai(client_raw)
MODEL = os.environ.get("MODEL_NAME")

# ---- Pydantic 模型 ----
class Paper(BaseModel):
    """学术论文信息"""
    title: str = Field(description="论文标题")
    authors: List[str] = Field(description="作者列表")
    year: int = Field(description="发表年份", ge=1900, le=2030)
    venue: str = Field(description="发表会议/期刊")
    
class PaperList(BaseModel):
    """论文列表"""
    papers: List[Paper]
    total: int = Field(description="论文总数")

# ---- 方法 1：手动 JSON mode（阶段 4 做法）----
def extract_papers_manual(text: str) -> PaperList:
    """手动解析 + 校验（需要自己写重试逻辑）"""
    prompt = f"""从下面的文本中提取论文信息，返回 JSON 格式：
{{
    "papers": [
        {{"title": "...", "authors": ["...", "..."], "year": 2024, "venue": "..."}},
        ...
    ],
    "total": 2
}}

文本：{text}
"""
    
    response = client_raw.chat.completions.create(
        model=MODEL,
        messages=[{"role": "user", "content": prompt}],
        response_format={"type": "json_object"}
    )
    
    json_str = response.choices[0].message.content
    print(f"[手动] 模型返回: {json_str[:150]}...\n")
    
    try:
        result = PaperList.model_validate_json(json_str)
        return result
    except ValidationError as e:
        print(f"[手动] 校验失败: {e}")
        # 这里需要自己写重试逻辑（阶段 4 做过）
        raise

# ---- 方法 2：Instructor（自动重试）----
def extract_papers_instructor(text: str) -> PaperList:
    """Instructor 自动重试（失败会把错误喂回模型，最多 3 次）"""
    prompt = f"从下面的文本中提取论文信息：\n\n{text}"
    
    result = client_instructor.chat.completions.create(
        model=MODEL,
        response_model=PaperList,  # 指定 Pydantic 模型
        messages=[{"role": "user", "content": prompt}],
        max_retries=3  # 失败自动重试
    )
    
    print(f"[Instructor] 解析成功: {result.total} 篇论文")
    return result

# ---- 测试文本 ----
sample_text = """
最近读了几篇论文：
1. Attention Is All You Need，Vaswani 等人 2017 年发在 NeurIPS，提出了 Transformer。
2. BERT: Pre-training of Deep Bidirectional Transformers，作者是 Devlin、Chang 和 Lee，2019 年 NAACL，预训练模型的里程碑。
"""

if __name__ == "__main__":
    print("=== 方法 1：手动 JSON mode（阶段 4 做法）===")
    try:
        result1 = extract_papers_manual(sample_text)
        for p in result1.papers:
            print(f"  - {p.title} ({p.year}), {p.venue}")
    except Exception as e:
        print(f"失败: {e}")
    
    print("\n=== 方法 2：Instructor（自动重试）===")
    result2 = extract_papers_instructor(sample_text)
    for p in result2.papers:
        print(f"  - {p.title} ({p.year}), {p.venue}")
        print(f"    作者: {', '.join(p.authors)}")
    
    # ---- 实验：故意给错误文本，观察重试 ----
    print("\n=== 实验：错误文本（触发重试）===")
    bad_text = "这段文本里根本没有论文信息，只是在闲聊。"
    try:
        result3 = extract_papers_instructor(bad_text)
        print(f"居然成功了（模型强行返回了）: {result3}")
    except Exception as e:
        print(f"重试 3 次后失败: {e}")
```

### 第 1 课自测

1. **Instructor 的自动重试是怎么工作的？**  
   提示：把 ValidationError 转成自然语言，作为新消息追加到 messages，再调一次模型。

2. **什么时候用 Instructor，什么时候手动 JSON mode？**  
   提示：复杂嵌套结构（列表、枚举、范围校验）用 Instructor；简单字典用 JSON mode。

3. **把 `year: int = Field(ge=1900, le=2030)` 改成 `ge=2025`，再跑一遍，观察 Instructor 如何重试**  
   提示：模型第一次可能返回 2017，Pydantic 报错"year 必须 >= 2025"，Instructor 把错误喂回模型。

## 第 2 课 · mem0 长期记忆（90 分钟）

### 目标

用 mem0 实现**跨会话记忆**：用户说"我喜欢喝咖啡"，下次对话 Agent 能记住并推荐咖啡店——而不是只靠 messages 列表（重启就丢）。

### 核心概念

**mem0 = 向量检索 + 时间衰减 + 自动去重**

- **User memory**：长期记忆，绑定用户 ID（如"user_123 喜欢咖啡"）
- **Session memory**：短期记忆，绑定会话 ID（如"这次对话在聊旅行"）
- **自动提取**：Agent 对话中提到的偏好、事实，mem0 自动存储
- **时间衰减**：旧记忆权重降低，最近的更重要

对比阶段 3 的 RAG：
- RAG 存"知识文档"（公司规章、技术手册），静态内容
- mem0 存"用户画像"（喜好、历史交互），动态更新

### 完整代码：`02_mem0_memory.py`

```python
# -*- coding: utf-8 -*-
"""
mem0 长期记忆示例
场景：用户多次对话，Agent 记住用户偏好
"""
import os
from dotenv import load_dotenv
from openai import OpenAI
from mem0 import Memory

load_dotenv()

# ---- 配置 ----
client = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY"),
    base_url=os.environ.get("OPENAI_BASE_URL")
)
MODEL = os.environ.get("MODEL_NAME")

# ---- 初始化 mem0（本地 SQLite 模式）----
# 生产环境可以用云端版（需要 MEM0_API_KEY）或接 Qdrant/Milvus
config = {
    "vector_store": {
        "provider": "chroma",
        "config": {
            "collection_name": "user_memories",
            "path": "./mem0_db"
        }
    }
}

memory = Memory.from_config(config)

USER_ID = "user_123"  # 模拟用户 ID

# ---- Agent 对话函数（带记忆）----
def chat_with_memory(user_input: str, user_id: str) -> str:
    """
    1. 检索相关记忆
    2. 拼接到 prompt
    3. 模型回复
    4. 自动提取新记忆存入 mem0
    """
    # 1. 检索相关记忆（top-3）
    relevant_memories = memory.search(user_input, user_id=user_id, limit=3)
    memory_context = "\n".join([m['text'] for m in relevant_memories]) if relevant_memories else "无相关记忆"
    
    # 2. 拼接 prompt
    system_prompt = f"""你是一个助手。以下是用户的历史记忆：

{memory_context}

基于这些记忆个性化你的回答。"""
    
    messages = [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": user_input}
    ]
    
    # 3. 模型回复
    response = client.chat.completions.create(
        model=MODEL,
        messages=messages
    )
    
    assistant_reply = response.choices[0].message.content
    
    # 4. 自动提取记忆（mem0 会分析对话，提取值得记住的信息）
    memory.add(user_input, user_id=user_id, metadata={"source": "user"})
    memory.add(assistant_reply, user_id=user_id, metadata={"source": "assistant"})
    
    print(f"[检索到的记忆] {len(relevant_memories)} 条")
    for m in relevant_memories:
        print(f"  - {m['text'][:50]}...")
    
    return assistant_reply

# ---- 模拟多轮对话 ----
if __name__ == "__main__":
    print("=== 第 1 次对话（初次见面）===")
    reply1 = chat_with_memory("我最近在学 Python，特别喜欢写 Agent。", USER_ID)
    print(f"AI: {reply1}\n")
    
    print("=== 第 2 次对话（建立偏好）===")
    reply2 = chat_with_memory("我不太喜欢 Java，觉得太啰嗦了。", USER_ID)
    print(f"AI: {reply2}\n")
    
    print("=== 第 3 次对话（测试记忆）===")
    reply3 = chat_with_memory("你能推荐一门适合我的编程语言吗？", USER_ID)
    print(f"AI: {reply3}\n")
    # 预期：Agent 会记得"喜欢 Python、不喜欢 Java"，推荐 Python 相关
    
    print("=== 第 4 次对话（跨会话记忆）===")
    # 模拟程序重启，USER_ID 不变
    reply4 = chat_with_memory("我上次跟你聊了什么？", USER_ID)
    print(f"AI: {reply4}\n")
    # 预期：能回忆起之前的对话（Python / Agent）
    
    # ---- 查看所有记忆 ----
    print("=== 用户的全部记忆 ===")
    all_memories = memory.get_all(user_id=USER_ID)
    for i, m in enumerate(all_memories, 1):
        print(f"{i}. {m['text'][:80]}... (创建时间: {m.get('created_at', 'N/A')})")
    
    # ---- 实验：删除记忆 ----
    # memory.delete_all(user_id=USER_ID)  # 清空该用户的所有记忆
    # print("记忆已清空")
```

## 第 3 课 · FastAPI 服务化 + SSE 流式（90 分钟）

### 目标

把 Agent 封装成 HTTP 服务，支持流式响应（SSE，Server-Sent Events），前端可以逐字显示 Agent 的回复（像 ChatGPT 那样）。

### 核心概念

**FastAPI = Python 的 Spring Boot**（路由、依赖注入、OpenAPI 文档自动生成）

**SSE = HTTP 流式协议**，服务端持续推送数据，客户端逐条接收（比 WebSocket 轻量）

```python
# 非流式（一次性返回）
@app.post("/chat")
def chat(request: ChatRequest):
    reply = agent_reply(request.message)
    return {"reply": reply}

# 流式（逐 token 推送）
@app.post("/chat/stream")
async def chat_stream(request: ChatRequest):
    async def event_generator():
        for chunk in agent_reply_stream(request.message):
            yield {"data": chunk}
    return EventSourceResponse(event_generator())
```

### 完整代码：`03_fastapi_agent.py`

```python
# -*- coding: utf-8 -*-
"""
FastAPI Agent 服务 + SSE 流式
启动：uvicorn 03_fastapi_agent:app --reload --port 8000
测试：curl -X POST http://localhost:8000/chat -H "Content-Type: application/json" -d '{"message":"你好"}'
流式：curl -N http://localhost:8000/chat/stream -H "Content-Type: application/json" -d '{"message":"介绍一下 Agent"}'
"""
import os
from dotenv import load_dotenv
from openai import OpenAI
from fastapi import FastAPI
from fastapi.responses import StreamingResponse
from pydantic import BaseModel
from typing import Iterator
import json

load_dotenv()

# ---- 配置 ----
client = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY"),
    base_url=os.environ.get("OPENAI_BASE_URL")
)
MODEL = os.environ.get("MODEL_NAME")

app = FastAPI(title="Agent Service", version="1.0")

# ---- 请求模型 ----
class ChatRequest(BaseModel):
    message: str
    user_id: str = "default_user"

class ChatResponse(BaseModel):
    reply: str
    tokens: int

# ---- Agent 逻辑（复用阶段 2 的简化版）----
def agent_reply(user_message: str) -> str:
    """非流式：一次性返回"""
    messages = [
        {"role": "system", "content": "你是一个助手"},
        {"role": "user", "content": user_message}
    ]
    response = client.chat.completions.create(
        model=MODEL,
        messages=messages
    )
    return response.choices[0].message.content

def agent_reply_stream(user_message: str) -> Iterator[str]:
    """流式：逐 token yield"""
    messages = [
        {"role": "system", "content": "你是一个助手"},
        {"role": "user", "content": user_message}
    ]
    stream = client.chat.completions.create(
        model=MODEL,
        messages=messages,
        stream=True
    )
    
    for chunk in stream:
        if chunk.choices[0].delta.content:
            yield chunk.choices[0].delta.content

# ---- 路由 1：非流式 ----
@app.post("/chat", response_model=ChatResponse)
def chat(request: ChatRequest):
    """同步返回完整回复"""
    reply = agent_reply(request.message)
    return ChatResponse(reply=reply, tokens=len(reply))

# ---- 路由 2：流式（SSE）----
@app.post("/chat/stream")
def chat_stream(request: ChatRequest):
    """流式返回（SSE 格式）"""
    def event_generator():
        for chunk in agent_reply_stream(request.message):
            # SSE 格式：data: {json}\n\n
            yield f"data: {json.dumps({'text': chunk})}\n\n"
        yield "data: [DONE]\n\n"
    
    return StreamingResponse(event_generator(), media_type="text/event-stream")

# ---- 路由 3：健康检查 ----
@app.get("/health")
def health():
    return {"status": "ok", "model": MODEL}
```

```python
# 方式 1：本地 Milvus Lite（无需 Docker）
connections.connect("default", uri="./milvus_demo.db")

# 方式 2：Docker Milvus Standalone

# ---- 创建 Collection（表）----
def create_collection():
    """定义 schema + 创建 collection"""
    if utility.has_collection(COLLECTION_NAME):
        print(f"Collection {COLLECTION_NAME} 已存在，跳过创建")
        return Collection(COLLECTION_NAME)
    
    # 定义字段（类似 SQL 的表结构）
    fields = [
        FieldSchema(name="id", dtype=DataType.INT64, is_primary=True, auto_id=True),
        FieldSchema(name="text", dtype=DataType.VARCHAR, max_length=2000),
        FieldSchema(name="embedding", dtype=DataType.FLOAT_VECTOR, dim=1536),  # DeepSeek embedding 维度
        FieldSchema(name="source", dtype=DataType.VARCHAR, max_length=200)
    ]
    
    schema = CollectionSchema(fields, description="知识库")
    collection = Collection(COLLECTION_NAME, schema)
    
    # 创建索引（HNSW 算法，适合高维向量）
    index_params = {
        "index_type": "HNSW",
        "metric_type": "IP",  # Inner Product（内积，余弦相似度的变体）
        "params": {"M": 16, "efConstruction": 200}
    }
    collection.create_index(field_name="embedding", index_params=index_params)
    print(f"Collection {COLLECTION_NAME} 创建成功")
    return collection

# ---- 获取 embedding ----
def get_embedding(text: str) -> list:
    """调用 DeepSeek embedding API（或本地模型）"""
    # 注意：DeepSeek 没有 embedding 接口，这里假设你用智谱/SiliconFlow
    # 如果没有，用 sentence-transformers 本地模型：
    # from sentence_transformers import SentenceTransformer
    # model = SentenceTransformer('sentence-transformers/all-MiniLM-L6-v2')
    # return model.encode(text).tolist()
    
    # 示例：假设你有 embedding API
    response = client.embeddings.create(
        model="text-embedding-ada-002",  # 替换成你的 embedding 模型
        input=text
    )
    return response.data[0].embedding

# ---- 插入文档 ----
def insert_documents(collection: Collection, docs: list):
    """批量插入文档（文本 + embedding）"""
    texts = [doc["text"] for doc in docs]
    sources = [doc["source"] for doc in docs]
    
    # 批量 embedding
    embeddings = [get_embedding(text) for text in texts]
    
    # 插入
    entities = [texts, embeddings, sources]
    collection.insert(entities)
    collection.flush()  # 确保写入磁盘
    print(f"插入 {len(docs)} 条文档")

# ---- 检索 ----
def search_documents(collection: Collection, query: str, top_k: int = 3):
    """向量检索"""
    query_embedding = get_embedding(query)
    
    # 加载到内存（首次查询需要）
    collection.load()
    
    # 检索
    search_params = {"metric_type": "IP", "params": {"ef": 64}}
    results = collection.search(
        data=[query_embedding],
        anns_field="embedding",
        param=search_params,
        limit=top_k,
        output_fields=["text", "source"]
    )
    
    docs = []
    for hits in results:
        for hit in hits:
            docs.append({
                "text": hit.entity.get("text"),
                "source": hit.entity.get("source"),
                "score": hit.score
            })
    return docs

# ---- 测试 ----
```

## 第 6 课 · 评测：LLM-as-judge（90 分钟）

### 目标

自动化测试 Agent 的回答质量：给定测试集（问题 + 标准答案），用另一个 LLM 当"评委"打分，替代人工评测。

### 核心概念

**LLM-as-judge = 用 LLM 评价 LLM**

传统测试：人工看回答是否正确（慢、不可扩展）  
LLM-as-judge：用 GPT-4 / Claude 当评委，自动打分（快、可批量）

评分维度：
- **准确性**（Accuracy）：答案是否正确？
- **完整性**（Completeness）：是否遗漏关键信息？
- **相关性**（Relevance）：是否跑题？
- **有害性**（Harmfulness）：是否有偏见/不当内容？

### 完整代码：`06_evaluation.py`

```python
# -*- coding: utf-8 -*-
"""
LLM-as-judge 评测示例
场景：测试 Agent 对知识库问题的回答质量
"""
import os
from dotenv import load_dotenv
from openai import OpenAI
from typing import List, Dict
import json

load_dotenv()

client = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY"),
    base_url=os.environ.get("OPENAI_BASE_URL")
)
MODEL = os.environ.get("MODEL_NAME")

# ---- 测试集 ----
test_cases = [
    {
        "question": "Python 的主要特点是什么？",
        "reference_answer": "Python 是解释型语言，语法简洁，支持多种编程范式，有丰富的库生态。",
        "category": "知识问答"
    },
    {
        "question": "什么是 Agent？",
        "reference_answer": "Agent 是能够感知环境、自主决策并采取行动的软件系统，通常由 LLM + 工具 + 循环组成。",
        "category": "概念解释"
    },
    {
        "question": "北京的天气怎么样？",
        "reference_answer": "需要调用天气查询工具获取实时数据。",
        "category": "工具调用"
    }
]

# ---- 被测 Agent（简化版）----
def agent_answer(question: str) -> str:
    """被测试的 Agent"""
    messages = [
        {"role": "system", "content": "你是一个助手，简洁回答问题。"},
        {"role": "user", "content": question}
    ]
    response = client.chat.completions.create(model=MODEL, messages=messages)
    return response.choices[0].message.content

# ---- 评委 LLM ----
def judge_answer(question: str, agent_answer: str, reference_answer: str) -> Dict:
    """用 LLM 当评委，给 Agent 的回答打分"""
    judge_prompt = f"""你是一个严格的评委。请评价以下 Agent 的回答质量。

问题: {question}
参考答案: {reference_answer}
Agent 回答: {agent_answer}

评分标准（0-10 分）：
- 准确性（5 分）：答案是否正确？
- 完整性（3 分）：是否遗漏关键信息？
- 相关性（2 分）：是否跑题？

请返回 JSON 格式：
{{
    "accuracy": 4,
    "completeness": 2,
    "relevance": 2,
    "total": 8,
    "reason": "答案基本正确，但遗漏了..."
}}
"""
    
    response = client.chat.completions.create(
        model=MODEL,
        messages=[{"role": "user", "content": judge_prompt}],
        response_format={"type": "json_object"}
    )
    
    return json.loads(response.choices[0].message.content)

# ---- 批量评测 ----
def run_evaluation(test_cases: List[Dict]):
    """运行评测"""
    results = []
    
    for i, case in enumerate(test_cases, 1):
        question = case["question"]
        reference = case["reference_answer"]
        category = case["category"]
        
        print(f"\n=== 测试用例 {i}/{len(test_cases)} ===")
        print(f"问题: {question}")
        print(f"类别: {category}")
        
        # 1. Agent 回答
        answer = agent_answer(question)
        print(f"Agent 回答: {answer}")
        
        # 2. 评委打分
        score = judge_answer(question, answer, reference)
        print(f"评分: {score['total']}/10")
        print(f"理由: {score['reason']}")
        
        results.append({
            "question": question,
            "category": category,
            "agent_answer": answer,
            "score": score
        })
    
    return results

# ---- 生成报告 ----
def generate_report(results: List[Dict]):
    """生成评测报告"""
    total_score = sum(r["score"]["total"] for r in results)
    avg_score = total_score / len(results)
    
    print(f"\n{'='*50}")
    print(f"评测报告")
    print(f"{'='*50}")
    print(f"测试用例数: {len(results)}")
    print(f"平均得分: {avg_score:.2f}/10")
    
    # 按类别统计
    by_category = {}
    for r in results:
        cat = r["category"]
        if cat not in by_category:
            by_category[cat] = []
        by_category[cat].append(r["score"]["total"])
    
    print(f"\n按类别统计:")
    for cat, scores in by_category.items():
        print(f"  {cat}: {sum(scores)/len(scores):.2f}/10 (共 {len(scores)} 题)")
    
    # 低分用例（< 6 分）
    low_scores = [r for r in results if r["score"]["total"] < 6]
    if low_scores:
        print(f"\n需要改进的用例（< 6 分）:")
        for r in low_scores:
            print(f"  - {r['question']}: {r['score']['total']}/10")
            print(f"    理由: {r['score']['reason']}")

# ---- 运行 ----
if __name__ == "__main__":
    results = run_evaluation(test_cases)
    generate_report(results)
    
    # 保存结果
    with open("evaluation_results.json", "w", encoding="utf-8") as f:
        json.dump(results, f, ensure_ascii=False, indent=2)
    print(f"\n结果已保存到 evaluation_results.json")
```

```python
# -*- coding: utf-8 -*-
"""
OpenAI Swarm 快速上手
场景：客服路由（咨询类→客服 Agent，技术类→工程师 Agent）
"""
from swarm import Swarm, Agent

client = Swarm()

# ---- 工具函数 ----
def查询订单状态(订单号: str) -> str:
    """客服 Agent 的工具"""
    # 模拟数据库查询
    return f"订单 {订单号} 状态：已发货，预计明天送达。"

def查询技术文档(关键词: str) -> str:
    """工程师 Agent 的工具"""
    # 模拟文档检索
    return f"找到关于 '{关键词}' 的文档：请参考 API 文档第 3.2 节。"

# ---- 定义 Agent ----
客服Agent = Agent(
    name="客服",
    instructions="你是客服，负责处理订单、退换货等咨询。如果是技术问题，转给工程师。",
    functions=[查询订单状态]
)

工程师Agent = Agent(
    name="工程师",
    instructions="你是技术支持工程师，负责回答 API、SDK 相关问题。",
    functions=[查询技术文档]
)

# ---- Handoff 逻辑（Agent 间转移）----
def转给工程师() -> Agent:
    """客服 Agent 调用这个函数，把对话转给工程师"""
    return 工程师Agent

客服Agent.functions.append(转给工程师)  # 客服可以转交

# ---- 运行 ----
if __name__ == "__main__":
    messages = [{"role": "user", "content": "我的订单 12345 什么时候到？"}]
    
    response = client.run(agent=客服Agent, messages=messages)
    print(f"客服: {response.messages[-1]['content']}\n")
    
    # 技术问题（触发 handoff）
    messages = [{"role": "user", "content": "怎么调用你们的 API？"}]
    response = client.run(agent=客服Agent, messages=messages)
    
    print(f"对话历史:")
    for msg in response.messages:
        role = msg.get("role", "")
        content = msg.get("content", "")
        if content:
            print(f"  {role}: {content}")
```

## 常见问题（FAQ）

### 1. Milvus 和 chromadb 性能差多少？

数据量 < 10 万：差异不明显  
数据量 > 100 万：Milvus 快 5-10 倍（HNSW 索引 + 分布式）  
建议：学习用 chromadb，生产用 Milvus

### 2. mem0 免费吗？

本地模式（SQLite + chromadb）免费  
云端托管版收费（但有免费额度）  
自己部署用本地模式即可

### 3. 为什么 FastAPI 而不是 Flask？

FastAPI 原生支持异步（async/await）、自动生成 OpenAPI 文档、Pydantic 集成  
Flask 是同步框架，异步要装插件  
企业新项目基本都用 FastAPI

### 4. LangSmith 必须用吗？

不必须。可以：
- 手动日志（print + 文件）
- 开源 Langfuse（可自部署）
- 云厂商自带的可观测（阿里云 / 腾讯云）

LangSmith 的优势是和 LangChain 深度集成，自动追踪

### 5. Instructor 支持流式吗？

部分支持（`stream=True` + `Partial`），但复杂结构会有坑  
生产建议：先非流式拿结构化结果，再流式输出文本部分

### 6. 怎么部署到服务器？

```bash
# 方式 1：直接跑（开发环境）
```

### 7. 成本怎么算？

假设用 DeepSeek（0.1 元 / 百万 token）：
- 单次对话（含检索 + 回复）：~2000 tokens = 0.0002 元
- 1 万次对话 = 2 元
- 比人工客服便宜 1000 倍+

### 8. 怎么防止 prompt injection？

- 输入校验（拒绝包含 "ignore previous instructions" 的输入）
- 分离系统 prompt 和用户输入（用 `system` / `user` role）
- 输出校验（Instructor + Pydantic 检查格式）
- 沙箱执行（工具调用在隔离环境跑）
